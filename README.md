# Newsletters do Luiz

Feed privado (não listado) do podcast gerado a partir das newsletters.

- Feed: https://luizpiovesana-mkt.github.io/newsletters-do-luiz/feed.xml
- `main`: script de publicação (`scripts/publish_feed.py`) e capa.
- `gh-pages`: o que o feed serve. É recriada a cada publicação como um commit único, com os últimos 60 episódios.
